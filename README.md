A modern browser-based implementation of the classic **Blackjack (21)** card game, built using **HTML, CSS, and Vanilla JavaScript**.

This project recreates the core Blackjack experience in the browser with a clean casino-inspired interface, responsive layout, animated cards, and a computer-controlled dealer. It was created to strengthen JavaScript fundamentals, DOM manipulation, game state management, and front-end development skills.

---

## ✨ Features

* ♠️ Classic Blackjack gameplay
* 🃏 Random card generation
* 👀 Hidden dealer card until the player's turn ends
* 💰 Chip balance system
* 🎲 Fixed betting system
* 🎨 Modern casino-inspired interface
* ⚡ Smooth card dealing animations
* 📱 Fully responsive design
* 🚫 Prevents invalid actions during gameplay
* 🏆 Win, Lose, Bust, Push and Blackjack outcomes

## 🎮 Gameplay

### Objective

Beat the dealer by getting a hand value as close to **21** as possible without going over.

### How to Play

1. Click **Start Game**.
2. You and the dealer are each dealt two cards.
3. One of the dealer's cards remains hidden.
4. Choose whether to:

   * **New Card (Hit)** to draw another card.
   * **Stand** to end your turn.
5. The dealer reveals their hidden card and draws until reaching **17 or more**.
6. The winner is determined and your chip balance is updated.
